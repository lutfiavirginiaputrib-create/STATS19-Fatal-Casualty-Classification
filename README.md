STATS19 Fatal Road Traffic Casualty Classification

This repository contains the supplementary code and research materials for the study:

Resampling Strategies for Classifying Fatal Road Traffic Casualties under Severe Class Imbalance: A Collision-Grouped Evaluation on STATS19 2023

Repository Contents

* LUTFIA_BISMILLAH_TERBARU.ipynb: Main research notebook.
* build_cohort_stats19_2023.py: Script for reconstructing and auditing the casualty-level cohort.

Dataset

The study uses the UK Department for Transport (DfT) STATS19 2023 road safety data.

The original data can be obtained from the official DfT Road Safety Open Data portal:
https://www.gov.uk/government/statistical-data-sets/road-safety-open-data

Reproducibility

The notebook and script are provided to document the data processing and analysis workflow. Please refer to the notebook for the analytical procedures and required Python packages.
